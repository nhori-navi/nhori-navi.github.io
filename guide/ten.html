TenMiruテンミル・見上げる・飛行機と星

  • 頭の上を通った飛行機が、どこへ行くのか分かったら
  • 「あと1分で真上」と知って、空を見上げられたら
  • 夜空の月や星座の名前を、その場で言えたら

TenMiru は、まわりを飛んでいる飛行機の行き先や機種が分かるアプリです。スマホを空に向けると、飛行機や月・星・星座の名前が重なります。行き先が分かると、いつもの空が少し広く感じられます。

アプリを開く

パソコンでも、地図・飛行機の一覧・図鑑・今日の空・よその空などが見られます。「空に向ける」やキャッチは、向きのセンサーがあるスマホで使えます。

楽しみ方

  1. アプリを開いて、位置情報の利用を許可します。地図と一覧に、まわりを飛んでいる飛行機が出ます。気になる機体を押すと、行き先や機種、写真が見られます。
  2. 「空に向ける」を押してスマホを空にかざすと、飛行機や月・星の名前が画面に重なります。
  3. 照準の円に飛行機を2秒入れ続けると「キャッチ」。図鑑に記録され、点数やバッジがもらえます。
  4. 「あと1:40で真上付近」と出たら、外に出て見上げてみてください。夜は星座の絵も重なります。

できること

  • まわりの飛行機の地図と一覧（行き先・機種・写真。軍用機も）
  • もうすぐ真上を通る飛行機のカウントダウン
  • スマホを空に向けると、飛行機・月・惑星・明るい星・星座（絵つき）の名前が重なる（カメラの映像にも）
  • キャッチ、レア度と点数、新しい都市・路線の印、バッジ、機種の図鑑
  • 今日の空の記録と、人に見せられるシェアカード
  • 国際宇宙ステーションの位置と、見える時刻の予報
  • よその空：地図で選んだ世界の空港や町の空を眺めて、別のノートに集める
  • 夜は暗い画面、ホーム画面に追加、記録の書き出し・読み込み

これから

  • 実装中iPhone での動作の確認
  • 予定名前の見直し（アプリの画面には、まだ旧名の「SoraMiru」と表示されます）

使う端末と許可

  • スマホ向けです。Android の Chrome で確かめています。iPhone は確認中です。
  • 位置情報：まわりの飛行機を探し、月や星の位置を計算するために使います。
  • 向きのセンサー：スマホが向いている方角を知るために使います（「空に向ける」のとき）。
  • カメラ：空の映像に飛行機や星を重ねるために使います。映像は保存も送信もしません。

できないこと・ずれること

  • 飛行機の位置は、各地の有志が置いた受信機の共同データです。受信機が少ない場所や、位置を発信していない機体は出ません。
  • 行き先は、便名から調べた共同データの推定です。経由便などで違うことがあります。
  • 方角はスマホのセンサー任せなので、数度〜十数度ずれることがあります。月や明るい星で合わせ直せます。
  • 星座は、雲で見えないときも計算した位置に表示します。

記録について

  • 図鑑・キャッチ・バッジ・今日の空・よその空ノートなどの記録は、使っている端末の中にだけ保存します。
  • 設定の「記録の保存」で、ファイルへの書き出しと読み込みができます。
  • ブラウザの設定で「サイトデータ」を消すと記録も消えます。同じアドレスのほかのミル シリーズのアプリの記録もいっしょに消えるので、ご注意ください。
