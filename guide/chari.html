ChariMiruチャリミル・自転車で走る・坂と記録

  • 坂の上り下りを見てから、ルートを決められたら
  • 着く時刻を、自分の走る速さで知れたら
  • 走った距離が、東海道や地球一周につながったら

ChariMiru は、坂の断面図を見ながらルートを選べる自転車のマップです。走った記録は積み上がって、東海道・シルクロード・地球一周…と、バーチャルの長い旅につながります。

アプリを開く

パソコンでは、ルート作り・坂の断面図・共有リンク・走った記録の表示が使えます。走るときはスマホで使ってください。

楽しみ方

  1. アプリを開いて、自転車の種類（ロード・クロス・街乗り・電動）と好みを選びます。
  2. 出発地・目的地（経由地も）を決めると、ルートと坂の断面図、着く時刻の目安が出ます。共有リンクで人に送れます。
  3. 「▶ 走る」で走行モード。曲がり角や坂の手前を声で案内し、速さ・距離を記録します。
  4. 走った記録は履歴に残り、合計の距離がバーチャルの旅を進めます。マスの塗りつぶし・峠のスタンプ・バッジもあります。

できること

  • ルート検索（出発・経由・目的、自転車の種類と好み）と、坂の断面図・勾配の色分け
  • 着く時刻の目安（坂の分も考え、走った記録から自分の速さを学ぶ）
  • ルートの共有リンク、GPX の書き出し・読み込み
  • 走行モード：地図いっぱいの表示、自動一時停止、曲がり角と坂の声の案内、外れたら引き直し
  • 走った記録（総走行距離・月ごとのグラフ）、マス塗り・峠のスタンプ帳・バッジ
  • バーチャルの長い旅（東海道 → ルート66 → シルクロード → シベリア鉄道 → 日本一周 → 地球一周 → 月）
  • 心拍・スピード・ケイデンスのセンサー（Bluetooth。対応するブラウザだけ）

これから

  • 実装中公開に向けた準備（ルート検索のしくみの見直し）

使う端末と許可

  • スマホ向けです。Android の Chrome で確かめています。iPhone でも使えます（センサーは対応するブラウザが必要です）。
  • 位置情報：走った道と速さを記録し、案内するために使います。
  • 画面のスリープ防止：走っている間に画面が消えないようにします。

できないこと・ずれること

  • ルートは地図データ（OpenStreetMap）から計算しています。走りにくい道が入ることがあります。
  • アプリを開いたまま、画面を点けたままでないと記録と案内が止まります。
  • 着く時刻は目安です。信号や向かい風は考えていません。

記録について

  • 走った記録・設定は、使っている端末の中にだけ保存します。GPX の書き出しで控えを取れます。
  • ブラウザの設定で「サイトデータ」を消すと記録も消えます。同じアドレスのほかのミル シリーズのアプリの記録もいっしょに消えるので、ご注意ください。
